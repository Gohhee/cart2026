# 장바구니 계산기

마트에서 계산 전에 담은 상품의 예상 금액을 확인하고, 계산대 금액과 차이를 비교하는 정적 PWA 웹앱입니다.

## 구현 가능성

- 웹앱으로 구현 가능합니다. 안드로이드와 아이폰 모두 브라우저에서 사용할 수 있고, 홈 화면에 추가하는 PWA 방식도 가능합니다.
- 수기 입력, 합계 계산, 할인 반영, 계산대 금액과의 차이 비교, 로컬 저장은 안정적으로 동작합니다.
- 바코드 자동 인식은 브라우저의 `BarcodeDetector` 지원 여부에 따라 달라집니다. 지원되지 않는 브라우저에서는 바코드 번호를 수기로 입력합니다.
- 라벨 사진 촬영은 가능합니다. 다만 가격표 OCR은 별도 OCR 엔진이나 서버가 필요해서 이번 MVP에서는 사진 참조와 수기 가격 입력으로 처리했습니다.
- 실제 바코드로 상품명과 가격을 자동 조회하려면 마트별 상품 DB나 외부 상품 API가 필요합니다. 가격은 매장과 행사에 따라 자주 바뀌므로 앱 안에서 직접 가격을 확인해 넣는 흐름이 가장 안전합니다.
- 휴대폰 카메라와 PWA 설치는 보통 HTTPS 환경에서만 안정적으로 허용됩니다. 실제 배포는 HTTPS가 적용된 호스팅에 올리는 방식이 좋습니다.

## 실행

정적 파일만으로 구성되어 있습니다. 카메라와 PWA 설치 검증은 `localhost` 서버에서 여는 편이 좋습니다.

```powershell
node dev-server.mjs
```

또는 Python이 설치되어 있다면 다음 명령도 사용할 수 있습니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## GitHub Pages 배포

이 앱은 빌드 과정이 없는 정적 PWA라서 GitHub Pages에 바로 올릴 수 있습니다.

1. GitHub 저장소의 루트에 이 폴더의 파일을 올립니다.
2. `gh-pages` 브랜치에 루트의 정적 파일을 push하면 GitHub Pages로 배포됩니다.
3. 배포 후 `https://<계정>.github.io/<저장소>/` 주소로 접속합니다.

사용자 사이트 저장소인 `<계정>.github.io`에 올리면 주소는 `https://<계정>.github.io/`가 됩니다.

## 검색 노출

`robots.txt`와 `noindex, nofollow` 메타 태그로 검색엔진 수집을 막도록 설정했습니다. 이 설정은 검색 노출을 줄이기 위한 요청 신호이며, URL을 아는 사람의 직접 접속을 막는 보안 기능은 아닙니다.

## 주요 기능

- 상품명, 라벨/바코드 번호, 가격, 수량, 메모 입력
- 바코드 스캔 시도 및 수기 입력 fallback
- 라벨 사진 촬영 후 상품에 첨부
- 장바구니 예산 입력 후 남은 금액, 초과 금액, 사용률 표시
- 상품 합계, 할인/쿠폰, 예상 결제액 표시
- 계산대 금액 입력 후 차이와 오차율 표시
- 상품 목록 수정, 수량 증감, 삭제, 전체 삭제
- 장바구니 목록 클립보드 복사
- Markdown 백업 파일 내보내기 및 불러오기
- 브라우저 로컬 저장 및 오프라인 캐시

## Markdown 백업 형식

앱은 `.md` 파일로 장바구니를 내보내고 다시 불러올 수 있습니다. 일반 Markdown 에디터에서 예산, 할인/쿠폰, 계산대 금액과 상품 표를 직접 수정할 수 있습니다.

```markdown
# 장바구니 계산기 백업

- 형식: cart-calculator-md-v1
- 예산: 50000
- 할인/쿠폰: 3000
- 계산대 금액: -

## 상품

| 상품명 | 바코드 | 가격 | 수량 | 메모 |
| --- | --- | ---: | ---: | --- |
| 우유 1L | 8801234567890 | 2980 | 2 | 행사 |
```

라벨 사진은 Markdown 백업에 포함하지 않습니다. 사진까지 장기 보관하려면 별도 이미지 파일이나 이후 IndexedDB 백업 기능을 붙이는 편이 좋습니다.
